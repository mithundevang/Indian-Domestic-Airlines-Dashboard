# Indian Domestic Airlines Analytics Dashboard

## Project Overview

A simple interactive Excel dashboard created to analyze Indian domestic airline data and identify useful patterns in flight volumes and ticket fares.

## Key Analysis

* Flight volume by airline
* Average and median ticket fares
* Ticket prices by number of stops
* Flight volume by departure time
* Source and destination analysis
* Monthly fare trends
* Airline-wise fare comparison

## Key Insights

* Non-stop flights have the lowest average fare.
* Three-stop flights cost 64.3% more than non-stop flights.
* Average fares are relatively similar across airlines.
* Monthly fares remain fairly stable throughout the year.

## Tools & Skills

Microsoft Excel, Advanced Excel, Power Query, DAX, Pivot Tables, Pivot Charts, VBA, and Data Visualization.
